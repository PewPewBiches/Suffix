Changelog

what changed

Including the parts that were broken. A list of only good news is not a changelog.

0.4.0 — one door, and an identity
addeda keyboard shortcut opens file actions for the Finder selection, and you choose which keys
changedthree Services entries became one panel that shows every action and greys out what does not apply, with the reason
changedsettings split into four tabs; the file actions are finally mentioned inside the app
changednew icon and notice, both built from one idea: a selected extension
addedsetup asks for each permission separately and says, in the same breath, what it does not allow — then converts a real file so you can see the whole chain working
addeda Permissions tab in Settings that measures what macOS is currently allowing rather than remembering what it once allowed
addedthe menu bar says No access to your files when Full Disk Access is missing, instead of running perfectly and converting nothing
removeddead code — an unused faithfulness check, and an error describing a Pages preview that turned out not to exist
fixedNSAppleEventsUsageDescription was missing, so macOS could deny the Finder shortcut and every iWork export with no prompt at all
fixedevery build since 0.1.0 reported itself as 0.1.0 — the version was a hand-edited string in the build script and nobody edited it
fixeda test that raced on shared state and failed about one run in five
0.3.1 — Pages export
fixed.pages → .pdf failed with “Pages must be installed” while Pages was installed. Current versions use the bundle identifier com.apple.Pages; 0.3.0 looked only for com.apple.iWork.Pages.
0.3.0 — text out of pictures
addedrename an image to .txt and get the words in it, via Vision
addedscanned PDFs fall back to reading the pages when there is no text layer
addedPages, Keynote and Numbers export through the app that made them
fixedsuffix was watching inside Photos libraries, raising a permission prompt it had no reason to ask for — and rewriting a file in there would corrupt the library
fixediWork apps are addressed by bundle identifier, so a document cannot be handed to an app that merely claimed the name “Pages”
0.2.0 — video, audio, documents
addedMOV ⇄ MP4 ⇄ M4V, audio extraction, and MP3 via ffmpeg or lame when installed
addedWord, RTF, OpenDocument, HTML and text to PDF — with the fidelity limit stated in the app
addedprogress in the menu bar; long videos ask before starting
fixedevery media conversion failed with “Cannot Open” — AVFoundation infers a file's type from its extension, which is the one thing this app cannot trust
0.1.0 — first release
addedrename to convert, across images and PDFs
addedseven-day undo, replace or keep both
fixedrenames arriving as a coalesced Removed | Renamed event were dropped, so conversions worked in a quiet folder and failed in a busy one
