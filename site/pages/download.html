First launch

1 · Open the disk image

Drag suffix into Applications, the way you have done a hundred times.

2 · macOS will block it

The app is unsigned, so Gatekeeper stops it once. Open System Settings → Privacy & Security, scroll to the line about suffix, click Open Anyway.

3 · Run the test

Setup asks for Full Disk Access, then converts a real file to prove the whole chain works. Why that matters →

Build it yourself

Would rather not run a stranger's binary? Reasonable. The whole thing is one command, and it takes about ten seconds.

git clone https://github.com/PewPewBiches/Suffix.git
cd Suffix && ./Scripts/build-app.sh && open build

Needs Xcode. Nothing else — no package manager, no dependencies to fetch.

On Windows?

suffix is macOS only, because it is built out of things only macOS has.

Its whole engine is Apple's — ImageIO, PDFKit, AVFoundation, Vision. A Windows version is not a port, it is a rewrite. Put your name down → and if enough people want it, it becomes worth doing.
