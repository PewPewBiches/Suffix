Nine steps, or one

You have a photo and you need a PDF. So you search “png to pdf”, pick one of the identical sites, and hand your file to a stranger's server.

Nothing is uploaded here. There is no window to open, no file picker, no “drag your file here”. You already know how to rename a file.

Installer

1 · Download

Get the latest release, open the disk image, drag suffix to Applications.

2 · Get past Gatekeeper

macOS blocks it once, because the app is unsigned. Open System Settings → Privacy & Security and click Open Anyway.

3 · Run the test

Setup asks for Full Disk Access, then converts a real file to prove it works. Why that matters →

Build it yourself

Rather not trust a stranger's binary? It is one command:

git clone https://github.com/PewPewBiches/Suffix.git
cd Suffix && ./Scripts/build-app.sh && open build
