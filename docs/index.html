Some things a filename can't say

“Merge these three” has no filename to type it into. Neither does “compress this, but how much?” Those live where you'd look for them — in the right-click menu.

Merge into one PDF

Select PDFs, images, or a mix of both. They combine in the order you see them, and the result is named after whatever they have in common.

Compress…

A Smallest / Balanced / Best toggle and a quality slider. The estimated size is measured — the first file is actually compressed at that setting — so the number moves when you do. If a file comes out bigger than it started, it's discarded rather than handed to you as an improvement.

Create ZIP archive

A separate item, deliberately. “Compress” and “zip” are different verbs that English happens to spell the same: one throws away detail, the other doesn't.

Install it

Download the latest release, open the disk image, and drag Suffix to Applications.

macOS will block it the first time

Suffix isn't signed with a paid Apple Developer certificate, so macOS will say it “cannot be verified”. That's Gatekeeper reacting to a missing $99-a-year signature, not to anything the app does.

  1. Open Suffix and let macOS block it
  2. Go to System Settings → Privacy & Security
  3. Scroll to the line about Suffix and click Open Anyway

You do this once.

Then let it reach your files

macOS protects Desktop, Documents and Downloads. Without access Suffix keeps running but silently does nothing in exactly the folders you use most — so setup asks for Full Disk Access, then offers a Test it button that converts a real file to prove the whole chain works.

Don't skip the test. A silent, healthy-looking failure is this app's characteristic way of going wrong, and the test catches it while you're still paying attention.

Rather not trust a stranger's binary?

Fair. Build your own — it takes about ten seconds:

git clone https://github.com/PewPewBiches/Suffix.git
cd Suffix && ./Scripts/build-app.sh && open build

○ MP3 needs a helper. macOS ships an MP3 decoder but no encoder, so Suffix uses ffmpeg or lame if one is installed — brew install ffmpeg. It looks for an encoder rather than bundling one. .m4a is the native equivalent and needs nothing.

Read this before converting a document you plan to send. Only iWork files convert exactly, because Suffix asks Pages or Keynote to export them. Everything else is re-laid-out by macOS's own text engine: text and basic formatting survive, but tables, columns, headers and footers, and exact pagination do not. Suffix says so on the notice — check the result.

Is this safe?

Your files never leave your Mac

Suffix contains no network code at all. Conversion uses only what ships with macOS — ImageIO, PDFKit, AVFoundation and Vision. No account, no service, nothing to sign in to.

Nothing is destroyed

Before anything is overwritten the original is copied aside and kept for seven days, so any conversion can be undone from the menu bar. Stored originals are deleted automatically after a week, rather than quietly becoming a second copy of your photo library.

You choose whether the original stays

After renaming photo.png to photo.pdf
Replacephoto.pdf — one file, as renaming implies
Keep bothphoto.pdf  +  photo.png, side by side

It only acts on a deliberate rename

Not on files you copy, download or move — only when you change a file's extension yourself, to something Suffix can actually produce, and the contents don't already match. Archives, code, other apps' libraries and anything it doesn't recognise are left exactly as they are. A .zip renamed to .png is untouched, and your Photos library is never opened.
