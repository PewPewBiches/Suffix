First launch

1 · Open the disk image

Drag suffix into Applications, the way you have done a hundred times.

2 · macOS will block it

The app is unsigned, so Gatekeeper stops it once. Open System Settings → Privacy & Security, scroll to the line about suffix, click Open Anyway.

3 · Let setup do the rest

It asks for one permission, explains what that permission does not allow, and then converts a real file in front of you. About a minute.

What it asks for, and what it can't do with it

Three permissions. Only the first is required, and macOS asks for the other two itself, at the moment they are needed. The app shows this same list in Settings, measured live — so if something stops working you can see which permission went away.

macOS asksBecauseWhat it does not allow
Full Disk Access Desktop, Documents, Downloads and iCloud Drive are protected. Without it suffix runs perfectly and converts nothing in the four folders you use. It reads a file only when you rename it to a different format, and only that file. There is no networking in the app at all.
Control Finder The keyboard shortcut arrives with no files attached, so it has to ask Finder what you selected. Only needed for the shortcut. One question per press: which files are selected. It cannot move, open or delete anything through this.
Control Pages, Keynote, Numbers A .pages file is a sealed bundle only Apple's app can open, so suffix asks it to export the PDF. Opens the document, exports, closes. It does not edit or save over your original.

You can revoke any of them at any time in System Settings. The app will tell you it has, rather than quietly stopping. The longer version →

Build it yourself

Would rather not run a stranger's binary? Reasonable. The whole thing is one command, and it takes about ten seconds.

git clone https://github.com/PewPewBiches/Suffix.git
cd Suffix && ./Scripts/build-app.sh && open build

Needs Xcode. Nothing else — no package manager, no dependencies to fetch.

On Windows?

suffix is macOS only, because it is built out of things only macOS has.

Its whole engine is Apple's — ImageIO, PDFKit, AVFoundation, Vision. A Windows version is not a port, it is a rewrite. Put your name down → and if enough people want it, it becomes worth doing.
