suffix for windows

suffix for windows

it doesn't exist yet. that's what this page is for.

the mac version is built almost entirely out of apple's own frameworks — imageio, pdfkit, avfoundation, vision. windows has none of them, so it isn't a port, it's a rewrite. worth doing if enough people actually want it.

no launch date, no email list you can't leave, no "exciting news soon".

the mac version is MIT and the whole engine is documented. it would go faster with someone who knows the platform.

there's no server behind this page, so Submit writes your answers into a GitHub issue and shows it to you before anything is posted. you can read it, edit it, or close the tab.

what a windows version would have to replace

  • ImageIO — reads and writes 20 image formatsno
  • PDFKit — pages, text layers, renderingno
  • AVFoundation — video and audio, hardware encodersno
  • Vision — on-device OCR, no model to downloadno
  • FSEvents — knowing a file was renamedno

windows has answers for all five, they're just other people's libraries with other people's licences. that's the work, and it's why this is a page with a form on it rather than a download.
