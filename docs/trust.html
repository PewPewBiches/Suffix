This app rewrites your files. That deserves a page rather than a sentence.

your files never leave your Mac

Suffix contains no network code at all. Conversion uses only what ships with macOS — ImageIO, PDFKit, AVFoundation and Vision. There is no account, no service, and nothing to sign in to.

network requestsnone
telemetry / analyticsnone
accountsnone
bundled binariesnone
sourceall of it, MIT

Don't take that on faith — the whole app is one command to build yourself:

git clone https://github.com/PewPewBiches/Suffix.git
cd Suffix && ./Scripts/build-app.sh && open build

it only acts on a deliberate rename

Not on files you copy, download or move. Only when you change a file's extension yourself, to something suffix can actually produce, and the contents do not already match.

skipped entirely

Photos libraries, Photo Booth, Music, iMovie and Final Cut libraries, application bundles, caches, node_modules, .git, and the Trash. A Photos library is a database, not loose files — rewriting anything inside would corrupt it.

nothing is destroyed

Before anything is overwritten the original is copied aside and kept for seven days, so any conversion can be undone from the menu bar. Stored originals expire on their own rather than growing forever.

why macOS says it is unidentified

Because it is unsigned.

Gatekeeper blocks the first launch and says the app “cannot be verified”. That is a statement about the missing signature, not about what the app does. Open System Settings → Privacy & Security and click Open Anyway; you do it once.

The same gap means suffix cannot use Notification Center — macOS refuses authorization without a signing identity — so it draws its own notice instead.

the permission it asks for, and why

Full Disk Access, so it can reach Desktop, Documents and Downloads.

Without it suffix keeps running and silently does nothing in exactly the folders you use most — which is worse than failing, because it looks like it is working. That is why setup ends in a test it button that converts a real file and shows you the result.

Do run the test. A silent, healthy-looking failure is this app's characteristic way of going wrong. The test catches it while you are still paying attention, instead of three days later.

The keyboard shortcut additionally asks Finder what you have selected, which macOS prompts for separately the first time. Declining it costs you the shortcut and nothing else — right-click still works.
